# 游戏内玩家心理模型与情感计算系统

## 项目描述

游戏内玩家心理模型与情感计算系统的bug修复项目。核心模块 `ai/player_psychology.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 情绪模型完全没做NPC不知道玩家的情绪
- 情绪识别完全没做不能从玩家行为推断情绪
- 行为预测完全没做不知道玩家接下来要做什么
- 性格模型完全没做每个玩家都一样
- 自适应对话完全没做NPC不会根据玩家情绪调整对话

## 运行测试
